# Interview Talking Points

## 30 Second Project Pitch

I built a public health BI dashboard using real CDC, Census, and USDA datasets to identify counties where health risk, poverty, uninsured rates, and food access barriers overlap. I designed the PostgreSQL schema, cleaned and joined the data, created SQL based scoring logic, and built dashboard ready views so stakeholders could rank counties and understand what is driving the risk.

## Why This Project Matters

This project is realistic because analysts rarely answer questions from a single clean table. The value comes from turning messy public datasets into a decision ready model that supports resource allocation.

## SQL Skills To Mention

* Joins across health, demographic, and food access datasets
* CTEs to make scoring logic readable
* Window functions for state and national ranking
* Views for dashboard consumption
* Indexes for query performance
* Materialized views for dashboard speed
* Stored procedure to refresh scoring logic

## Business Analyst Angle

I did not just write SQL. I started with the stakeholder decision, defined KPIs, created a repeatable scoring method, and designed the dashboard around the questions a program manager would ask.

## Resume Bullets

* Built a PostgreSQL BI portfolio project using CDC, Census, and USDA public datasets to identify counties with overlapping health, economic, and food access risk.
* Designed normalized tables, dashboard ready views, indexes, and SQL scoring logic to support county level prioritization and executive reporting.
* Used joins, CTEs, subqueries, window functions, and performance tuning to create practical analysis workflows from real public data.
* Developed a stakeholder focused dashboard concept with KPIs, county rankings, risk tiers, and drilldowns for business decision support.
